**Tagline:** Build agents you can explain.

The mark combines an open **C** with an internal **X**. The C represents cognition,
context, and a controlled system boundary. The X represents models, tools, memory,
and governance converging through an inspectable execution point.

## Palette

| Role | Color |
|---|---|
| Dark canvas | `#050712` |
| Dark surface | `#0A1022` |
| Primary amber | `#F6B44B` |
| Information cyan | `#6EE7FF` |
| Light text | `#F4F7FB` |
| Dark mark | `#0A1022` |

Amber is the identity and active-focus color. Cyan is secondary and should indicate
information or connected runtime paths rather than compete with the brand mark.

## Usage rules

- Preserve the symbol's aspect ratio and clear space.
- Keep the open C readable before the internal X.
- Use the icon without the tagline below 32 px.
- Use the tagline in repository headers, landing pages, documentation covers, and
  larger video compositions—not in favicons or compact navigation.
- Use the dark lockup on dark surfaces and the light lockup on light surfaces.
- Do not add gradients, shadows inside the mark, outlines, or decorative nodes.
- Do not recolor the symbol with generic neon or rainbow palettes.

## Minimum sizes

- Favicon: 16 × 16 px, using `cogentrex-icon.svg`.
- Compact navigation: 32 × 32 px.
- Horizontal lockup: 160 px wide or larger.

## Current limitation

The horizontal SVG lockups use a geometric system-font wordmark so they render
cleanly in the repository and application today. Before print production or
trademark filing, convert the approved wordmark lettering to outlined vector paths
in a design tool and retain the current symbol geometry and spacing.
