## Omitted-concept status summary

The added canonical pages separate nearby ideas that the original 47-page set could otherwise overclaim:

- **Implemented within a bounded local contract:** PII-before-persistence and optional Docker-only execution isolation.
- **Partial:** provider capability parity; skills/project instructions; cost/usage budgets; structured output/caching; multimodal/artifacts; in-process background jobs; compliance/red teaming; agent communication security; Kubernetes artifacts.
- **Not implemented:** learning/optimization/drift, redacted run export/share, and generic self-reflection.
- **Deferred:** distributed agent networks, high-throughput serving, fine-tuning/vertical adaptation, scheduled autonomy, and public deployment.

A stub, manifest, unit-tested helper, or adjacent capability is not promoted to `implemented`. In particular: tool-error feedback is not generic self-reflection; a local verifier is not a distributed network; RAG/skills are not fine-tuning; an HPA manifest is not throughput evidence; persistence redaction is not a safe sharing workflow; and local Compose is not public deployment.
